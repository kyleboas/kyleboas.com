Blur-lift entrance

Visible first, then the last six pixels lift out of a five-pixel blur.

Currently reading the weekend's matches.

Three notes filed since Tuesday.

One draft still arguing with itself.

[data-s="1"]{animation-delay:80ms}
[data-s="2"]{animation-delay:160ms}
@keyframes fi{to{opacity:1;filter:blur(0);transform:translateY(0)}}
@media(prefers-reduced-motion:reduce){
  .fade{opacity:1;filter:none;transform:none;animation:none!important}
}

Dotted-rule link row

The underline is a repeating gradient on the baseline, so hover never shifts layout.

Writing Projects Elsewhere

Set inline, the same rule sits under a phrase mid-sentence without breaking the line's rhythm.

06

Check that draws itself

Clipping the mark before its rotation walks the pen from one free end to the other.

Notes app / globals.css

.check::after{content:"";position:absolute;left:5px;top:2px;width:4px;height:8px;
  border:solid #fff;border-width:0 2px 2px 0;transform:rotate(45deg)}
.check:checked::after{animation:checkmark-in 160ms var(--ease-out) 40ms both}
@keyframes checkmark-in{
  from{opacity:0;transform:rotate(45deg) scale(.8);clip-path:inset(75% 100% 0 0)}
  30%{opacity:1;clip-path:inset(75% 0 0 0)}
  to{opacity:1;transform:rotate(45deg) scale(1);clip-path:inset(0 0 0 0)}
}
07

Alternating tile surfaces

Parchment, white, dark. The surface change is the divider, so nothing else has to be.

One idea per surface

The tile holds a single claim and the evidence for it. Everything else waits for the next surface.

White is a pause

The canvas tile carries proof: a table, a list of sources, a short quotation.

Dark is the turn

The dark tile is where the argument changes direction. Read the publication for the version with the football in it.
