UI collection

Interface parts taken out of the projects they already ship in — a personal site, a notes app, a scouting dashboard, a football publication, a one-purpose tool. Each one runs on this page rather than sitting in a screenshot, and the code underneath it is the code that runs.

Nothing here is a component library. They are decisions: how a page enters, how a list shows state, how density stays readable, how one surface becomes the divider for the next.

Check that draws itself

The mark is an L of two borders turned forty-five degrees. Clipping it before the rotation walks the pen from one free end, through the corner, to the other; the box fills first and the mark lands a beat later.

Notes app / diver-notes/src/app/globals.css / component

.check::after{content:"";position:absolute;left:5px;top:2px;width:4px;height:8px;
  border:solid #fff;border-width:0 2px 2px 0;transform:rotate(45deg)}
.check:checked::after{animation:checkmark-in 160ms var(--ease-out) 40ms both}
@keyframes checkmark-in{
  from{opacity:0;transform:rotate(45deg) scale(.8);clip-path:inset(75% 100% 0 0)}
  30%{opacity:1;clip-path:inset(75% 0 0 0)}
  to{opacity:1;transform:rotate(45deg) scale(1);clip-path:inset(0 0 0 0)}
}

Alternating tile surfaces
